# Доска публикаций

Интерактивное веб-приложение на чистом HTML, CSS и JavaScript, объединяющее работу с DOM, формами, событиями и HTTP-запросами (fetch, async/await, JSON).

## Запуск

1. Скачайте файлы проекта: `index.html`, `style.css`, `app.js`, `README.md`.
2. Откройте `index.html` в браузере (двойной клик или через локальный сервер, например `python -m http.server`).
3. Внешние зависимости и сборка не требуются.

## Функциональность

- **Загрузка публикаций (GET)** — кнопка «Загрузить публикации» запрашивает `https://jsonplaceholder.typicode.com/posts?_limit=5`, проверяет `response.ok`, читает JSON и выводит заголовок и текст 5 публикаций через DOM (`textContent`).
- **Создание публикации (POST)** — форма с валидацией (обрезка пробелов, запрет пустых полей), `addEventListener` + `preventDefault`, отправка `{title, body, userId: 1}` с заголовком `Content-Type: application/json` на `https://jsonplaceholder.typicode.com/posts`. При успехе выводится заголовок и ID из ответа.
- **Состояния и ошибки** — сообщения «загрузка/отправка» во время запроса, обработка сетевых сбоев и HTTP-ошибок через `response.ok` и `try/catch/finally`. Кнопки блокируются на время запроса и снова активируются в `finally` для повторной попытки.

## Результаты проверки

| Сценарий | Ожидаемый результат | Статус |
|---|---|---|
| Нажатие «Загрузить публикации» | Появляются 5 записей с заголовками и текстом | ✅ |
| Отправка пустых полей / только пробелов | Сообщение об ошибке, запрос не отправляется | ✅ |
| Отправка корректных заголовка и текста | HTTP 201, данные публикации выводятся на страницу, сообщение об успехе | ✅ |
| Замена GET-адреса на `.../postz` (404) | Понятное сообщение об ошибке, кнопка снова активна | ✅ |
| Восстановление правильного адреса | Загрузка снова работает | ✅ |
